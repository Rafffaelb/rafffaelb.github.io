AI-based Fault Detection in Drones Using FPGA

Drones/UAVs AI/ML FPGA Chaos Theory Embedded Systems

🚁 Project Overview

This project developed an embedded system for real-time failure diagnosis in drones using artificial intelligence and chaos-based detection methods (SAC-DM) implemented on FPGA platforms.

The system enables autonomous UAVs to detect and classify mechanical and electrical failures in real-time, improving flight safety and enabling predictive maintenance for commercial and industrial drone applications.

🔬 Research Context

Position: Guest Researcher in Electrical Engineering
Institution: Technische Universität Dresden (TUD), Germany
Period: 2023 - 2024
Funding: CAPES (Brazilian Federal Agency for Support and Evaluation of Graduate Education)

This research focused on adaptive complex systems and reconfigurable computing, investigating how chaos theory principles can be applied to real-time fault detection in autonomous systems.

⚙️ Technical Approach

SAC-DM Methodology

SAC-DM (Statistical Analysis of Chaos - Diagnostic Method) is a chaos theory-based approach for detecting anomalies in complex dynamic systems. The method analyzes the chaotic behavior of sensor data to identify deviations from normal operational patterns.

Key Components

  • ▸ FPGA Implementation: Hardware acceleration for real-time processing of sensor streams
  • ▸ AI/ML Integration: Machine learning models for fault classification and prediction
  • ▸ Chaos Analysis: Real-time calculation of Lyapunov exponents and other chaotic indicators
  • ▸ Sensor Fusion: Integration of multiple sensor modalities (IMU, vibration, current sensors)

Technologies Used

Xilinx FPGAs Vivado HLS Python/TensorFlow C/C++ VHDL/Verilog MATLAB/Simulink

Research Impact

This work demonstrates the viability of implementing sophisticated AI-based diagnostics on resource-constrained embedded platforms. The combination of chaos theory and machine learning provides a novel approach to fault detection that is both computationally efficient and highly accurate, paving the way for more reliable autonomous drone systems in commercial and industrial applications.
