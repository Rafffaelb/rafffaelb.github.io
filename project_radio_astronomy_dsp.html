Reconfigurable Computing Applications in Radio Astronomy DSP

FPGA RFSoC Digital Signal Processing Radio Astronomy Vivado Real-time Systems

Project Overview

This project focuses on developing reconfigurable computing applications for digital signal processing in radio astronomy as part of the BINGO (Baryon Acoustic Oscillations in Neutral Gas Observations) radiotelescope project at the Federal University of Campina Grande (UFCG).

The work involves utilizing FPGA-based systems to implement real-time DSP algorithms for processing cosmological signals, enabling the study of large-scale structures in the universe through neutral hydrogen observations.

Research Context

Position: Postdoctoral Researcher in Electrical Engineering / Radio Astronomy
Institution: Federal University of Campina Grande (UFCG), Brazil
Period: 2024 - Present
Funding: FAPESQ (Research Support Foundation of the State of Paraíba)
Collaboration: INAF — Osservatorio Astronomico di Cagliari, Italy (external associate, remote)

The BINGO project aims to map the distribution of neutral hydrogen in the universe using intensity mapping techniques, requiring sophisticated real-time signal processing capabilities to handle the massive data throughput from the radio telescope.

Technical Details

Key Technologies

  • ▸ FPGA Platforms: SKARAB / Xilinx devices and RFSoC ZU47DR for hardware acceleration
  • ▸ Development Tools: Vivado Design Suite for HDL synthesis and implementation, CASPER toolflow
  • ▸ Programming: VHDL/Verilog for hardware description, Python/C++ for control and analysis (KATCP protocol)
  • ▸ Signal Processing: FFT, polyphase filter banks, channelization, filtering, and correlation algorithms
  • ▸ Data Transport: 40 GbE QSFP+ links and custom Ethernet framing for high-throughput astronomical data capture

Implementation Focus

  • ▸ Real-time spectral analysis of radio frequency signals
  • ▸ High-throughput data processing for cosmological observations
  • ▸ Energy-efficient computation for continuous operation
  • ▸ Hardware-optimized algorithms for radio interferometry

Applications

Intensity Mapping

Processing signals for large-scale structure mapping of the universe through neutral hydrogen emissions

Radio Interferometry

Real-time correlation and beamforming for multi-antenna radio telescope arrays

RFI Mitigation

Radio frequency interference detection and suppression in real-time

Data Reduction

On-the-fly data compression and processing to manage large data volumes

Research Impact

This work contributes to the advancement of radio astronomy instrumentation by leveraging reconfigurable computing to achieve:

  • ▸ Significant reduction in data processing latency compared to traditional CPU-based approaches
  • ▸ Lower power consumption for continuous astronomical observations
  • ▸ Scalable architectures adaptable to various radio astronomy applications
  • ▸ Enhanced signal-to-noise ratio through optimized digital filtering techniques
