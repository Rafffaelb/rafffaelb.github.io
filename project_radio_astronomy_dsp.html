Reconfigurable Computing Applications in Radio Astronomy DSP

FPGA Digital Signal Processing Radio Astronomy Vivado Real-time Systems
📡
Project Overview

This project focuses on developing reconfigurable computing applications for digital signal processing in radio astronomy as part of the BINGO (Baryon Acoustic Oscillations in Neutral Gas Observations) radiotelescope project at the Federal University of Campina Grande (UFCG).

The work involves utilizing FPGA-based systems to implement real-time DSP algorithms for processing cosmological signals, enabling the study of large-scale structures in the universe through neutral hydrogen observations.

Research Context
Position: Postdoctoral Researcher
Institution: Federal University of Campina Grande (UFCG)
Period: 2024 - Present
Funding: FAPESQ
The BINGO project aims to map the distribution of neutral hydrogen in the universe using intensity mapping techniques, requiring sophisticated real-time signal processing capabilities to handle the massive data throughput from the radio telescope.
Technical Details

▸ Key Technologies

  • FPGA Platforms: Xilinx devices
  • Development Tools: Vivado Design Suite
  • Programming: VHDL/Verilog, Python/C++
  • Signal Processing: FFT, Channelization

▸ Implementation Focus

  • Real-time spectral analysis
  • High-throughput data processing
  • Energy-efficient computation
  • Hardware-optimized algorithms

🎯 Applications

Intensity Mapping

Processing signals for large-scale structure mapping of the universe through neutral hydrogen emissions

Radio Interferometry

Real-time correlation and beamforming for multi-antenna radio telescope arrays

RFI Mitigation

Radio frequency interference detection and suppression in real-time

Data Reduction

On-the-fly data compression and processing to manage large data volumes

Research Impact

This work contributes to the advancement of radio astronomy instrumentation by leveraging reconfigurable computing to achieve:

Significant latency reduction
Lower power consumption
Scalable architectures
Enhanced SNR ratios
